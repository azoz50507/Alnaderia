# مزرعة ومشاتل النادرية

موقع عربي وإنجليزي لمزرعة النادرية في الفرعين، أحد رفيدة، عسير. ملفات HTML وCSS وJavaScript جاهزة للنشر، دون حزم خارجية أو حاجة إلى خادم تطبيقات.

الموقع: [alnaderia.com](https://alnaderia.com) · واتساب: **+966 50 318 4880**

## التشغيل المحلي

يتطلب Python 3 فقط. من مجلد المشروع في PowerShell:

```powershell
.\start.ps1
```

افتح [المعاينة العربية](http://127.0.0.1:4173/) أو [English preview](http://127.0.0.1:4173/en/). لإيقاف المعاينة اضغط `Ctrl+C`.

إذا منعت إعدادات PowerShell تشغيل السكربت، شغّل Python مباشرة:

```powershell
python scripts/serve.py
```

لتغيير المنفذ المشغول: `.\start.ps1 -Port 4174` أو `python scripts/serve.py --port 4174`. خادم المعاينة متاح على الجهاز المحلي فقط ويعرض صفحة 404 المخصصة. افتح الموقع عبر الخادم؛ فتح HTML مباشرة من القرص لا يدعم مسارات الموقع كاملةً.

## التعديل والتحقق

- محتوى الصفحتين الرئيسيتين مصدره `scripts/build_site.py`. بعد تعديله، شغّل `python scripts/build_site.py` لإعادة توليد `index.html` و`en/index.html` معًا.
- التصميم العام في `assets/style.css`، والتفاعلات في `assets/experience.js` وتنسيقها في `assets/experience.css`.
- شغّل `python scripts/build_site.py` أيضًا بعد تعديل CSS أو JavaScript؛ يضيف المولّد بصمة تلقائية إلى روابط الملفات حتى يحصل الزوار على الإصدار المحدّث.
- صفحات الخصوصية في `privacy.html` و`en/privacy.html`، وصفحة الخطأ في `404.html`. تصميمها المشترك في `assets/pages.css`.
- الخطوط والصور محلية داخل `assets/`. حافظ على نص بديل مناسب للصور، وحجم مضغوط يناسب الجوال.
- عند تغيير رقم التواصل أو المنتجات، حدّث بيانات الصفحات والتفاعلات والخصوصية معًا، ثم راجع اللغتين.

نفّذ فحص الملفات قبل النشر:

```powershell
python scripts/verify.py
```

أو `.\start.ps1 -Check`. يفحص الروابط والملفات المحلية، ومعرّفات الأقسام، وبعض أساسيات إمكانية الوصول، وبيانات محركات البحث وJSON-LD، وتوافق بنية الصفحات بين اللغتين. لا يرسل أي طلبات إلى الإنترنت.

راجع أيضًا في المتصفح: عرض الجوال والكمبيوتر، تنقّل لوحة المفاتيح وإغلاق النوافذ بـ`Escape`، تصفية المنتجات، إضافة المنتجات وإزالتها، الاحتفاظ بالاختيارات بعد إعادة التحميل، والرسالة التي يفتحها زر واتساب.

## الطلبات والبيانات

قائمة الطلب تساعد الزائر على تجهيز استفسار. يُحفظ في المتصفح فقط معرّف كل منتج وكميته؛ معلومات التواصل لا تُحفظ في التخزين المحلي. لا تصل رسالة إلى المزرعة حتى يرسلها الزائر داخل واتساب. يؤكّد فريق المزرعة الأسعار والتوفّر والتوصيل مباشرة، ولا يتضمن الموقع دفعًا إلكترونيًا أو مخزونًا لحظيًا.

الصفحات الحالية لا تُحمّل ملفات التحليلات أو المؤثرات القديمة (`analytics.js` و`cinematic.js` و`script.js`). إذا تقرّر تفعيل التحليلات لاحقًا، يجب أولًا تحديث تجربة الموافقة وصفحتي الخصوصية بما يطابق التنفيذ الفعلي.

## الصور

صور المحصول والمونة والمشتل مولّدة بأداة `image_gen` المدمجة وتُعرض كصور تعبيرية، وليست صورًا توثيقية للمزرعة أو عبواتها الفعلية. النسخ المستخدمة في الموقع بصيغة WebP المحلية، مع الاحتفاظ بأصول PNG. تفاصيل الملفات وصياغات التوليد في [`assets/image-prompts.md`](assets/image-prompts.md). استبدلها بصور المنتجات الفعلية عند توفرها، وحدّث النصوص البديلة والتنويه في المصدر.

## تفعيل النسخة العامة

الملفات المولّدة جاهزة لاستضافة ثابتة. يحتوي المشروع على `CNAME` للنطاق `alnaderia.com` و`robots.txt` و`sitemap.xml`. عند استخدام GitHub Pages، يجب أن يشير مصدر النشر إلى جذر الفرع الذي يحتوي هذه الملفات، مع إعداد النطاق وشهادة HTTPS لدى الاستضافة. لا يحتاج الموقع إلى أمر بناء في الاستضافة؛ توليد الصفحات مطلوب فقط عند تعديل المصدر.

بعد مراجعة النسخة المحلية ونشر التحديث بالطريقة المعتمدة لديك، افحص `/` و`/en/` وصفحتي الخصوصية وصفحة غير موجودة على النطاق العام. التشغيل المحلي لا ينشر التعديلات تلقائيًا.
